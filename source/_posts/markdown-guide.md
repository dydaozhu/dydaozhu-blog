写博客只需要记住下面这些，剩下的边写边查就行。

## 标题

```markdown
# 一级标题（文章里一般不用，标题已经是 H1）
## 二级标题
### 三级标题
```

## 强调

```markdown
**加粗**  *斜体*  ~~删除线~~  `行内代码`
```

效果：**加粗**、*斜体*、~~删除线~~、`行内代码`。

## 列表

```markdown
- 无序项
- 无序项

1. 有序项
2. 有序项
```

## 链接与图片

```markdown
[链接文字](https://example.com)
![图片说明](/images/example.jpg)
```

图片放在 `source/images/` 目录下，引用时写 `/images/文件名`。

## 引用

```markdown
> 这是一段引用。
```

> 这是一段引用。

## 代码块

用三个反引号包起来，开头写上语言名就能高亮：

````markdown
```js
console.log('hello')
```
````

## 表格

```markdown
| 语法 | 效果 |
| --- | --- |
| `**粗**` | 加粗 |
| `*斜*` | 斜体 |
```

| 语法 | 效果 |
| --- | --- |
| `**粗**` | 加粗 |
| `*斜*` | 斜体 |

## 分隔线

```markdown
---
```

## 小心这两点

1. 中英文之间建议手动加空格，读起来舒服很多；
2. 一行不要写太长，源码里换行不影响渲染，但方便以后改。
